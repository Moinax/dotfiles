BIOS — Veille silencieuse & suspend

Gigabyte Z790 AORUS MASTER X · manuel officiel BIOS Intel série 700 · entrer dans le BIOS : touche Suppr au démarrage, mode Advanced (F2 bascule Easy/Advanced)

Pourquoi : sous Linux, le CPU ne dispose que des C-states C1/C2/C3 (fallback ACPI) — jamais les états profonds C6/C8/C10. Il ne se met donc jamais en veille profonde, même au repos → il reste chaud → ventilos audibles, éveillé comme en s2idle. Cause quasi certaine : les C-States sont désactivés/capés dans le BIOS. Les réactiver = idle froid + (avec Fan Stop) veille réellement silencieuse, sans dépendre du deep/S3 qui plante.

② Smart Fan 6 — pour que les ventilos s'arrêtent vraiment SILENCE

Depuis n'importe quel écran BIOS, appuie sur F6 (ou barre d'accès rapide ▸ Smart Fan 6). Régler pour chaque ventilo : CPU_FAN, CPU_OPT, SYS_FAN1…5, pompes.

Option (nom exact BIOS)Régler surNote
FAN/PUMP StopEnabledLa clé. Le ventilo s'arrête sous la température limite de la courbe
Fan Speed ControlSilent(ou Normal) — profil calme
FAN/PUMP ModeSlopeMontée linéaire, pas par paliers brusques
Temperature Interval— Intervalle large = moins de variations de régime

Sur la courbe : amène le point de départ (0 RPM / « Stop ») vers ~50 °C pour le CPU et le boîtier → repos & veille = ventilos coupés. Pense à TUNE ALL pour appliquer à tous les headers, puis Save Fan Profile.

④ Si un jour tu veux retenter le deep/S3 — leviers anti-hang

⚠️ Le deep/S3 fige actuellement le PC (LED carte mère figée à 03, hard reboot obligatoire). Ne le retente que volontairement, travail sauvegardé. Le faisceau pointe vers un S3 cassé au niveau firmware/plateforme — pas garanti réparable côté OS.

  • Côté Linux (de mon côté) : passer le driver nvidia-open → nvidia propriétaire permettrait NVreg_EnableGpuFirmware=0 (fix S3 classique, impossible sur les modules open). À garder pour plus tard.

⑤ Navigation BIOS & vérif au retour

  • Suppr au boot = entrer · F2 = Easy/Advanced · F10 = sauver & quitter
  • Alt + F = Option Search : tape C State, ASPM, S3… pour sauter direct au réglage (anglais)
  • F11 = Favoris · Insert sur une option = l'ajouter aux favoris (★)
  • Après reboot, je relance le check : cat /sys/devices/system/cpu/cpu0/cpuidle/state*/name doit afficher C6/C8/C10 via intel_idle (au lieu des C*_ACPI actuels) → preuve que l'idle profond est actif.
