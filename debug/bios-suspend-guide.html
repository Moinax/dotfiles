BIOS — Veille silencieuse & suspend

Gigabyte Z790 AORUS MASTER X · manuel officiel BIOS Intel série 700 · entrer dans le BIOS : touche Suppr au démarrage, mode Advanced (F2 bascule Easy/Advanced)

2026-11-11: S3 recovery validated. Three real deep-sleep cycles passed after disabling Above 4GB MMIO BIOS assignment, with Above 4G Decoding and ReBAR already disabled. These are separate options. See the validated settings below and the investigation record. The earlier idle/fan-tuning notes below are historical and are not prerequisites for this S3 fix.
Pourquoi : sous Linux, le CPU ne dispose que des C-states C1/C2/C3 (fallback ACPI) — jamais les états profonds C6/C8/C10. Il ne se met donc jamais en veille profonde, même au repos → il reste chaud → ventilos audibles, éveillé comme en s2idle. Cause quasi certaine : les C-States sont désactivés/capés dans le BIOS. Les réactiver = idle froid + (avec Fan Stop) veille réellement silencieuse, sans dépendre du deep/S3 qui plante.

④ Validated S3 recovery — 2026-11-11

BIOS F11 contains a 32-bit address truncation in its S3 handler for I2C controller 0000:00:15.2. Linux had placed that controller above 4 GiB. The following configuration moved it below 4 GiB and passed three real S3 entry/wake cycles with the usual NVIDIA driver and desktop. This strongly supports the mechanism; the exact failing firmware instruction was not captured.

Settings ▸ IO Ports — use Alt+F and search MMIO if the option is elsewhere.

OptionValidated valueEvidence
Above 4GB MMIO BIOS assignmentDisabledDecisive change: removed the high PCI window and moved the controller to 0x40402000.
Above 4G DecodingDisabledDisabling this alone left the controller above 4 GiB. It is separate from MMIO BIOS assignment.
Re-Size BAR SupportDisabledAlready disabled during failed tests. Retained in the validated configuration.

After a BIOS reset or update, verify these distinct options and the actual address: head -n 1 /sys/bus/pci/devices/0000:00:15.2/resource. The validated start address is 0x0000000040402000; it must remain below 0x100000000 for this mechanism to be avoided. A low address alone does not validate every aspect of sleep: confirm real S3 entry and wake.

All diagnostic hooks were removed. No NVIDIA replacement, permanent kernel parameter, sensor blacklist, or BIOS update was required. See the complete evidence and limits.

⑤ Navigation BIOS & vérif au retour

  • Suppr au boot = entrer · F2 = Easy/Advanced · F10 = sauver & quitter
  • Alt + F = Option Search : tape C State, ASPM, S3… pour sauter direct au réglage (anglais)
  • F11 = Favoris · Insert sur une option = l'ajouter aux favoris (★)
  • Après reboot, je relance le check : cat /sys/devices/system/cpu/cpu0/cpuidle/state*/name doit afficher C6/C8/C10 via intel_idle (au lieu des C*_ACPI actuels) → preuve que l'idle profond est actif.
